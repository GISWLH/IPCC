# Generated results

Run `python examples/generate.py` from the repository root to produce `demos/` here. It contains PNG/PDF exports and a JSON manifest with the synthetic arrays, package versions, seed, and source references.

Generated runs are ignored by Git. Keep the reviewed README previews in `assets/demos/` and the generating code in `examples/`. Use `--output-dir` to preserve multiple runs; files with the same demo names are regenerated in the selected directory.
