# IPCC Plotting Style

**Climate figures. Grounded in source.**

Find a visual pattern in public IPCC Working Group I code, understand its design choices, and turn it into a figure you can run and adapt. Built for climate researchers, with particular attention to precipitation, runoff, water stress, scenario comparison, and ensemble uncertainty.

A local, source-grounded skill for Codex and Claude. Search runs entirely offline with Python’s standard library. No API key, embedding service, or database required.

[Quick start](#quick-start) · [Demos](#demos) · [Use as a skill](#use-as-a-skill) · [Project guide](docs/project-guide.md) · [Contributing](CONTRIBUTING.md)

> Independent community project, inspired by IPCC-WG1 figures. Not affiliated with or endorsed by the IPCC. Demo values are synthetic and are not scientific findings.

## Demos

Three examples share a restrained visual language: consistent scenario colors, legible labels, explicit uncertainty, and traceable style references. Every preview below is generated by [examples/generate.py](examples/generate.py).

### 01 · Scenario trajectories

Compare median trajectories without hiding the ensemble spread. Shading shows the 5th–95th percentiles of 80 synthetic members; scenario labels illustrate familiar color conventions.

![Synthetic scenario trajectories with uncertainty bands](assets/demos/scenarios.png)

### 02 · Spatial change and agreement

A Robinson projection, a diverging scale centered on zero, and stippling keep the field and its qualification visible together. The agreement mask is an illustrative rule, not a statistical assessment.

![Synthetic precipitation-change map with low-agreement dots](assets/demos/precipitation.png)

### 03 · Regional ensemble distributions

Compare four regions and three scenarios with the same color vocabulary. Boxes show the interquartile range; whiskers cover the 5th–95th percentile range, with outside values omitted.

![Synthetic regional runoff distributions by scenario](assets/demos/ensembles.png)

**Reproduce all three:**

```bash
python -m pip install -r requirements-demo.txt
python examples/generate.py
```

PNG previews, PDF exports, synthetic data, package versions, and retrieved style references are written to `results/demos/`. A fixed seed makes the data reproducible. The small Natural Earth land layer is bundled, so generation needs no runtime downloads. See the [demo guide](examples/README.md) for SVG export and adaptation notes.

## Quick start

Use Python 3.10 or newer for retrieval. The optional demo environment is tested with Python 3.12.

```bash
git clone https://github.com/GISWLH/IPCC.git
cd IPCC

# Retrieve code you can inspect locally; no installation required.
python scripts/search_ipcc_examples.py "scenario uncertainty" --family time_series --limit 3

# Machine-readable results, including commit and bundled source path.
python scripts/search_ipcc_examples.py "stippling" --family map --json
```

The main command returns the best matching chunk per source file and favors **code that actually exists in the bundle**. Each result includes its upstream repository, original path, commit, and local availability. Add `--all-types` to also search references to excluded datasets, documents, and output artifacts.

For repository and language filters, use the lower-level interface:

```bash
python scripts/ipcc_rag_search.py "uncertainty" --repo Chapter-11 --source-only --unique-files
```

Search uses lightweight keyword scoring. Try concrete plotting terms such as `fill_between`, `boxplot`, `stippling`, or `colorbar`; it does not provide semantic or embedding search. Indexed language labels can describe an upstream repository rather than the individual file.

## Use as a skill

Expose this checkout as `ipcc-plotting-style` using your assistant’s skill installation mechanism, or point the assistant directly to [SKILL.md](SKILL.md). Keep `scripts/` and `references/` beside that file when copying the skill.

Example requests:

- “Use the IPCC plotting style skill to draw a precipitation-change map with a centered colorbar and low-agreement hatching.”
- “Adapt this runoff time series with consistent scenario colors and uncertainty bands. Cite the source examples.”
- “Make a multi-panel figure comparing regional ensemble distributions and projected changes.”

The skill follows a concrete sequence: classify the figure, retrieve evidence, read the relevant source, build the plot, and cite its provenance. Real data paths and scientific assumptions remain yours to specify.

Retrieval tests also run without third-party packages; demo tests are explicitly skipped when the plotting dependencies are absent. CI installs the demo dependencies and runs both. See [CONTRIBUTING.md](CONTRIBUTING.md) for the expected checks and preview update workflow.

## Scope and attribution

This is a plotting and provenance toolkit. It does not reproduce the full IPCC assessment, ship large climate datasets, or guarantee that every historical upstream script runs in a modern environment. The archived notebooks have had narrative cells and rendered outputs removed.

When adapting an upstream pattern, cite the original repository, source path, and commit returned by search. Demo manifests record the style examples used during generation; those references do not validate the synthetic data or its scientific interpretation.

The source bundle contains material with upstream-specific terms. A blanket project-wide license has not been declared; consult the original source before redistribution. See [provenance and licensing](docs/provenance.md) for attribution, known metadata limitations, and the Natural Earth credit.
